Back up your data

Your supplies, projects, resins, measurements, and photos stay on this device. A backup file is how you move them to another device, or keep them safe.

Restoring replaces this device's saved data with the data in the file.

AI suggestions

Project ideas and reading supplies from photos use your own Anthropic API key, and you pay Anthropic for what you use. The key is stored only on this device, so don't enter it on a shared device. If you also host other projects on the same GitHub Pages address, those pages could read it, so use a key with a low spending limit.

Install on iPhone

Open this page in Safari, tap Share, then Add to Home Screen. After that, it opens like an app and works offline. The installed app has separate storage from Safari, so make a backup first if you've already entered data in Safari.
